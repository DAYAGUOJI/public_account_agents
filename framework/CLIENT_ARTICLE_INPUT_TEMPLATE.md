# 客户定制公众号输入模板

客户需求可以很发散，但进入框架前必须先收敛成清楚的约束。

## 客户目标

- 客户/项目：
- 推文目标：品牌传播 / 活动预热 / 研究解读 / 产品介绍 / 招募 / 其他
- 目标读者：
- 希望读者读完后采取的动作：

## 客户要求原文

```text
在这里粘贴客户的原始要求。不要先替客户润色。
```

## 素材

```text
图片：
文档：
链接：
表格：
视频：
其他：
```

## 可变约束

- 标题方向：
- 语气：正式 / 科普 / 活泼 / 品牌感 / 学术克制 / 其他
- 篇幅：
- 必须出现的信息：
- 禁止出现的信息：
- 是否需要保留客户原话：
- 是否需要引用来源：

## 事实边界

```text
产品/项目状态：
数据来源：
人名/机构名：
发布时间：
审批要求：
```

## 输出要求

默认输出：

- `requirements_brief.md`：客户要求归纳和风险点。
- `article_spec.json`：公众号结构化内容。
- `image_replacements.md`：素材替换清单。
- `inject_article.js`：可复制到公众号编辑器控制台运行的脚本。
