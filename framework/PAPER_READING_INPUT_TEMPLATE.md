# 论文读书笔记公众号输入模板

这个模板来自附件中的“文献阅读笔记 / Literature reading notes”框架，是本项目每次论文分享默认调用的不变部分。

## 基本信息

- 笔记编号：
- 论文题目：
- 期刊/会议：
- 作者：
- 关键词：
- DOI / arXiv / URL：
- 本期署名：

## 论文原材料

```text
在这里放论文 PDF 路径、arXiv 链接、论文正文、摘要或同学整理的笔记。
```

## 固定读书笔记框架

### 1 介绍

#### 1.1 研究动机

这篇论文为什么要做这个问题？现有研究或现实场景中有什么缺口？

#### 1.2 研究目标

论文希望解决什么核心问题？目标应与论文原文保持一致。

#### 1.3 研究任务

论文把目标拆成了哪些具体任务、假设、建模问题或实验问题？

### 2 相关研究

论文把自己放在哪些研究脉络里？它与既有方法、数据集、系统或理论有什么关系？

### 3 研究方法

论文使用了什么方法、模型、实验设计、分析框架或系统流程？需要说明关键步骤和为什么这样设计。

### 4 研究应用与实践

论文结果如何落到应用、实验、系统、案例或实践启示中？如果论文只提供实验验证，不要扩写成已落地应用。

## 输出要求

默认输出：

- `paper_reading_note.json`：按 `framework/templates/literature_reading_note.schema.json` 组织。
- `article_spec.json`：由固定读书笔记框架生成的公众号结构。
- `inject_article.js`：可复制到公众号编辑器控制台运行的脚本。
- `publication_assets.json`：公众号标题、封面 brief、最终生图提示词和输出路径。
- `assets/cover-wechat-landscape.png`：2.35:1 横版公众号封面，必须保存到当前文章目录。

标题与封面为论文流程的必选交付，不得只停留在对话或临时目录。标题应准确表达论文结论边界；封面默认不生成文字、Logo 或水印，避免模型文字失真，标题由公众号后台单独填写。
